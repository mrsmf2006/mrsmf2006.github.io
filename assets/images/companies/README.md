# Company Logos / راهنمای جایگزینی لوگوها

شما می‌توانید تصاویر یا لوگوهای واقعی را با هر یک از نام‌های زیر در این پوشه قرار دهید یا جایگزین کنید:

1. **نجم استودیو**: `najm-studio.png` یا `najm-studio.svg`
2. **تکنوورس**: `technoverse.png` یا `technoverse.svg`
3. **هزارتو**: `hezartoo.png` یا `hezartoo.svg`
4. **طیوران صنعت پویا**: `toyooran.png` یا `toyooran.svg`
5. **املین**: `amline.png` یا `amline.svg`
6. **جمشیدبار**: `jamshidbar.png` یا `jamshidbar.svg`
7. **آفاق کهکشانی**: `afagh.png` یا `afagh.svg`

سیستم به صورت خودکار در صورت وجود فایل PNG/JPG آن را نمایش می‌دهد و در غیر این صورت از لوگوی وکتوری باکیفیت SVG به عنوان فال‌بک استفاده می‌کند.
