# Image Guide for Portfolio

## 📸 Profile Photo

**File**: `profile.jpg` (place in this folder)

### Requirements:
- **Size**: 800x800px minimum (square format)
- **Format**: JPG or PNG
- **Quality**: High resolution (for retina displays)
- **Background**: Professional setting or clean background
- **Style**: Professional headshot or creative portrait

### Tips:
- Good lighting is crucial
- Face should be clearly visible
- Avoid overly casual photos
- Consider your industry (DevOps = tech-forward, professional)

- **Color**: Any color (grayscale filter applied automatically)
- **Quality**: Vector-based or high-res raster

- Hover effect removes grayscale (shows original colors)
- If you can't get official logos, text-based placeholders work too

## ❓ Common Issues

### Image Not Showing
1. Check file name spelling (case-sensitive)
2. Verify file is in correct folder
3. Check file format (.jpg, .png)
4. Clear browser cache

### Image Looks Blurry
1. Use higher resolution (2x for retina)
2. Save as PNG for better quality
3. Avoid over-compression

### Image Too Large (Slow Loading)
1. Compress with TinyPNG
2. Resize to recommended dimensions
3. Convert to WebP format
4. Use progressive JPG
